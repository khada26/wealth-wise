General Instructions

  1. The player will take a turn rolling the dice.
  2. Once rolled, the number shown is how many tiles the player will jump.
  3. The landed tile determines the type of question the student will answer.
  4. If it lands on EASY, the questions are multiple choice. If AVERAGE, the student will answer True or False. If DIFFICULT, it will be an identification question.
  5. Each student must answer a total of 10 questions.
  6. Checking will be done after the whole game and facilitated on the results board.
